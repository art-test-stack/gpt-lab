# GPT Lab · Experiments

A small, dependency-free experiment recap. Compare learning curves, CORE results,
training configurations, and recorded runtime. No Python server, training packages,
API credentials, or GPU are needed to view it.

The default view is empty until real results are supplied. The explicit preview
button generates synthetic example data; it is never an experiment result.

See [the dashboard guide](https://github.com/art-test-stack/gpt-lab/blob/master/docs/results_dashboard.md)
for export, data format, and deployment instructions.
